# システムアーキテクト試験 午前II 一問一答

システムアーキテクト試験の午前II問題を年度別に選択し、1問ずつ解答・採点できるブラウザツールです。問題文と選択肢はテキストとして表示し、提出すると公式解答、正解の解説、各選択肢の判定理由が表示されます。図・数式を含む問題は、右側の問題冊子PDFも参照できます。

## 元の問題

<https://www.ipa.go.jp/shiken/mondai-kaiotu/nl10bi0000009lh8-att/2025r07h_sa_am2_qs.pdf>

## 過去問題PDF

平成21年度以降にIPAで公開されているシステムアーキテクト午前IIの問題PDFを `exam-pdfs/` に保存しています。令和2年度（2020年度）はシステムアーキテクト試験自体が実施されていないため、問題PDFと解答PDFはありません。

画面上部の「出題年度」から年度を選択できます。令和7〜3年度（2025〜2021年度）、令和元年度（2019年度）、平成30〜21年度（2018〜2009年度）の計16年度が一問一答に対応しています。令和2年度（2020年度）はシステムアーキテクト試験が実施されていないため、問題ページと問題PDFはありません。各年度の問題PDF・公式解答PDFの取得元は `exam-pdfs/manifest.txt` に記録しています。

各問題にはメモ欄があります。メモは入力時に使用中のブラウザへ自動保存され、同じブラウザであれば年度・問題ごとに後から編集又は削除できます。

## 起動方法

リポジトリのルートで、任意の静的HTTPサーバーを起動してください。

```sh
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。`file://` でも動作しますが、PDFの埋め込み表示はHTTP経由が安定します。
