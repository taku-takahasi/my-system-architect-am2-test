# システムアーキテクト試験 午前II 一問一答

令和7年度春期システムアーキテクト試験（午前II・25問）を、1問ずつ解答・採点できるブラウザツールです。問題文は元PDFを画像化して表示するため、原文の文字・図・数式・レイアウトを変更せず確認できます。提出すると公式解答と解説が表示され、右側の問題冊子PDFも参照できます。

## 起動方法

リポジトリのルートで、任意の静的HTTPサーバーを起動してください。

```sh
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。`file://` でも動作しますが、PDFの埋め込み表示はHTTP経由が安定します。
