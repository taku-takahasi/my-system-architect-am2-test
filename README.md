# システムアーキテクト試験 午前II 一問一答

令和7年度春期システムアーキテクト試験（午前II・25問）を、1問ずつ解答・採点できるブラウザツールです。問題文と選択肢はテキストとして表示し、図がある問題は図も併せて表示します。提出すると公式解答と解説が表示され、右側の問題冊子PDFも参照できます。

## 過去問題PDF

平成21年度以降にIPAで公開されているシステムアーキテクト午前IIの問題PDFを `exam-pdfs/` に保存しています。年度によって試験実施時期が異なるため、公開されている資料のみを収録しています。令和2年度（2020年度）は該当する問題PDFが公開ページにありません。

画面上部の「出題年度」から年度を選択できます。令和7年度、令和6年度、令和5年度は一問一答に対応しており、その他の年度は現在、問題PDFを参照できます。順次、各年度の問題文・解答・解説を一問一答形式に追加します。

## 起動方法

リポジトリのルートで、任意の静的HTTPサーバーを起動してください。

```sh
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。`file://` でも動作しますが、PDFの埋め込み表示はHTTP経由が安定します。
